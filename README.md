# MDAPP — готовые сборки и обновления

Это канал распространения приложения MDAPP (офлайн-конвертер документов в Markdown для Windows x64).

## Установка

1. В разделе Releases скачайте установщик `MDApp-Setup-<версия>-win-x64.exe`.
2. Запустите его. Первая установка выполняется для текущего пользователя, права администратора не нужны.

## Обновления

Приложение проверяет файл `latest.json` последнего релиза и предлагает кнопку «Обновить». Скачиваются только изменённые компоненты. Целостность защищена подписью ECDSA.
