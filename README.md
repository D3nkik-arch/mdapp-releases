# MDAPP — готовые сборки и обновления

Это канал распространения приложения MDAPP (офлайн-конвертер документов в Markdown для Windows x64).

## Установка

Готовый выпуск для Windows x64 — [MDAPP 0.1.6](https://github.com/D3nkik-arch/mdapp-releases/releases/tag/v0.1.6). Если вам передали полный файл `MDApp-Setup-0.1.6-win-x64.exe`, закройте приложение и запустите установщик.

На GitHub полный установщик разделён на две части. Скачайте их и следуйте инструкции на странице выпуска. Установка выполняется для текущего пользователя Windows.

## Обновления

В меню «О программе» доступна кнопка «Проверить обновления». Для обновления через приложение используются подписанное описание выпуска и архивы изменённых компонентов. Версия для ручной установки может появиться раньше, чем обновление станет доступно через кнопку.
